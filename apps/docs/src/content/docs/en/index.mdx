## How to read a component page

Each component separates its content into four views:

- **Design:** visual contract, anatomy, variants, and tokens;
- **Usage:** when to use it, content, and best practices;
- **Implementation or availability:** technology-specific instructions;
- **Accessibility:** requirements and evidence for that implementation.

For the complete production catalog, use the
[stable v1 documentation](/ds-tis/).
