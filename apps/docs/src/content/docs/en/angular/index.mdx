The Angular output is a native, independent library. It reuses the visual
contract from `ds-tis/css`, but does not import components, source, or runtime
from the Web and React outputs.

<Aside type="caution" title="Workspace beta">
  `@tis/angular` is not published on the public npm registry. Current evidence
  installs the local `dist/tis-angular-0.0.0-beta.0.tgz` tarball into a separate
  Angular consumer.
</Aside>

## Validated installation

```bash
npm install ./dist/tis-angular-0.0.0-beta.0.tgz ds-tis
```

In the application's global CSS:

```css
@import "ds-tis/css";
@import "@angular/cdk/overlay-prebuilt.css";
```

## Current coverage

- `@tis/angular/accordion`: standalone directives over Angular Aria;
- `@tis/angular/alert`: standalone composition with a live region and optional dismissal;
- `@tis/angular/avatar`: image, initials or icon with fallback and accessible name;
- `@tis/angular/badge`: presentational component with tone and variant;
- `@tis/angular/breadcrumb`: native navigation, link, current-page and separator directives;
- `@tis/angular/button`: standalone component with a native `button`;
- `@tis/angular/card`: composition directives on native semantic elements;
- `@tis/angular/checkbox`: standalone component with a native checkbox and Angular Forms;
- `@tis/angular/combobox`: standalone component with Angular Aria, local filtering, Form Field, and Angular Forms;
- `@tis/angular/divider`: native `hr` directive with orientation and a decorative option;
- `@tis/angular/form-field`: standalone wrapper with a projected control, label, hint, error and public IDs/ARIA;
- `@tis/angular/input`: standalone component with a native input, Form Field, and Angular Forms;
- `@tis/angular/menu`: standalone directives over Angular Aria for Action Menu;
- `@tis/angular/modal`: standalone component over CDK Overlay/Portal/A11y;
- `@tis/angular/pagination`: controlled navigation with links, previous/next and ellipses;
- `@tis/angular/popover`: standalone component over CDK Overlay/Portal/A11y;
- `@tis/angular/radio`: standalone group with native radios and Angular Forms;
- `@tis/angular/select`: standalone component with a native select and Angular Forms;
- `@tis/angular/skeleton`: decorative shapes and a loading-region directive;
- `@tis/angular/spinner`: indeterminate indicator with an accessible status or decorative mode;
- `@tis/angular/table`: standalone directives over native table semantics;
- `@tis/angular/tabs`: standalone directives over Angular Aria;
- `@tis/angular/textarea`: standalone component with a native textarea, counter, and Angular Forms;
- `@tis/angular/toast`: notification service and standalone live region;
- `@tis/angular/toggle`: standalone component with a native switch and Angular Forms;
- `@tis/angular/tooltip`: standalone component over CDK Overlay/Portal;

Each entrypoint has independent imports, bundles, and tests. Consumer checks cover
production build, forms/submit, keyboard, focus, responsiveness, theme, and Axe.
