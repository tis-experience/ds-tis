    <h3>Installation</h3>

    Configure the namespace first as described in the [registry catalog](../../registry/).

    <Tabs syncKey="package-manager">
      <TabItem label="npm">

```sh
npx shadcn@latest add @tis/button
```

      </TabItem>
      <TabItem label="pnpm">

```sh
pnpm dlx shadcn@latest add @tis/button
```

      </TabItem>
      <TabItem label="yarn">

```sh
yarn dlx shadcn@latest add @tis/button
```

      </TabItem>
      <TabItem label="bun">

```sh
bunx --bun shadcn@latest add @tis/button
```

      </TabItem>
    </Tabs>

    The item installs `button.tsx`, the shared helper, pinned dependencies, and
    ensures `@import "ds-tis/css"` in global CSS.
  </ComponentPanel>

  <ComponentPanel id="accessibility" label="Accessibility" slug="button" technology="react">
    <Aside type="tip" title="Executed gate">
      Button participates in the React/Vite consumer gate that validates a
      production build, real form submission, focus, and Axe with the other
      eight beta components.
    </Aside>

    <h3>Consumer responsibility</h3>

    <ul>
      <li>provide an accessible name through text or <code>aria-label</code>;</li>
      <li>declare the correct <code>type</code> inside forms;</li>
      <li>preserve disabled/loading states and the public focus ring;</li>
      <li>validate the real context, including copy, flow, and contrast.</li>
    </ul>
  </ComponentPanel>
