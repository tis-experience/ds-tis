The React implementation is now available in beta through a versioned shadcn
registry. Source code is added to the consumer project while continuing to use
the public DS TIS CSS, tokens, and anatomy.

<Aside type="note" title="Source distribution, not a React package">
  `@tis/react` remains private and is not a public dependency. The beta contract
  is the source registry under `/registry/v1`, validated in an installed
  React/Vite consumer with browser interaction and Axe.
</Aside>

## How it works

shadcn distributes source into the app. Base UI provides behavior and state
management only when needed; native elements and React composition cover simple
cases. The provider does not define the visual language: `ds-tis/css` and TIS
tokens remain canonical.

The `v1` channel stabilizes registry addresses. Because this line is still beta,
installed source should be reviewed with the rest of the application code.

## Beta guarantees

1. official registry schema validated by the shadcn CLI;
2. TypeScript source and gzip budgets checked in CI;
3. installation through the `@tis` namespace in a clean React/Vite fixture;
4. production build, keyboard, states, responsiveness, and Axe in a browser;
5. a machine-readable catalog marking each implementation as `stable`, `beta`,
   or `unavailable`.

For all remaining components, use the stable Web CSS implementation until
`docs/api/components.json` publishes `implementations.react.status: "beta"`.
