A linha Web CSS é a implementação estável da v1: tokens DTCG, CSS, runtimes
JavaScript opt-in e contratos consumíveis sem exigir um framework específico.

<Aside type="note" title="Linha recomendada hoje">
  Use Web CSS em projetos que precisam do catálogo atual ou que não dependem de um
  adapter oficial de framework. A vNext não interrompe nem descontinua esse
  contrato.
</Aside>

## Quando escolher Web CSS

- a aplicação consegue importar CSS e, quando necessário, JavaScript opt-in;
- a equipe quer compor componentes com HTML nativo ou com a stack de sua escolha;
- o projeto precisa consumir a linha estável enquanto adapters oficiais evoluem;
- interoperabilidade e baixo acoplamento ao framework são requisitos.

## Cobertura

- tokens Foundation, Semantic e Component;
- temas light/dark e motor white-label;
- catálogo atual de componentes, com disponibilidade documentada;
- runtimes opt-in para os padrões interativos App-ready;
- Storybook HTML/Vite e documentação estática da v1.

## Evolução

A vNext não elimina esta linha. Tokens, tema e conhecimento continuam neutros; os
adapters de framework adicionam ergonomia e comportamento sem substituir o contrato
web quando ele for a melhor escolha.
