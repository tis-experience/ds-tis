A saída Angular é uma biblioteca nativa e independente. Ela reutiliza o contrato
visual de `ds-tis/css`, mas não importa componentes, source ou runtime das saídas
Web e React.

<Aside type="caution" title="Beta de workspace">
  `@tis/angular` ainda não está publicado no registry público do npm. A evidência
  atual usa o tarball local `dist/tis-angular-0.0.0-beta.0.tgz`, instalado num
  consumer Angular separado.
</Aside>

## Instalação validada

```bash
npm install ./dist/tis-angular-0.0.0-beta.0.tgz ds-tis
```

No CSS global da aplicação:

```css
@import "ds-tis/css";
@import "@angular/cdk/overlay-prebuilt.css";
```

## Cobertura atual

- `@tis/angular/accordion`: diretivas standalone sobre Angular Aria;
- `@tis/angular/button`: componente standalone com `button` nativo;
- `@tis/angular/checkbox`: componente standalone com checkbox nativo e Angular Forms;
- `@tis/angular/input`: componente standalone com input nativo, Form Field e Angular Forms;
- `@tis/angular/modal`: componente standalone sobre CDK Overlay/Portal/A11y;
- `@tis/angular/popover`: componente standalone sobre CDK Overlay/Portal/A11y;
- `@tis/angular/radio`: grupo standalone com radios nativos e Angular Forms;
- `@tis/angular/select`: componente standalone com select nativo e Angular Forms;
- `@tis/angular/tabs`: diretivas standalone sobre Angular Aria;
- `@tis/angular/textarea`: componente standalone com textarea nativo, contador e Angular Forms;
- `@tis/angular/toggle`: componente standalone com switch nativo e Angular Forms;

Cada entrypoint tem import, bundle e testes próprios. Os testes do consumer cobrem
build de produção, forms/submit, teclado, foco, responsividade, tema e Axe.
