Use as superfícies machine-readable antes de gerar uma tela ou componente:

1. `docs/api/consumer-context.json` para descobrir tecnologias e formas de distribuição;
2. `docs/api/components.json` para consultar categoria, readiness e disponibilidade;
3. `implementations.react.item` para formar o comando `@tis/<item>`;
4. a página do componente para Design, Uso, Implementação e Acessibilidade;
5. o source instalado como contrato efetivo da API React copiada na aplicação.

## Regra de seleção

Use React somente quando `implementations.react.status` for `beta` ou `stable`.
Quando o status for `unavailable`, use Web CSS ou declare explicitamente uma
adaptação local. Não invente item de registry nem export de `@tis/react`.
