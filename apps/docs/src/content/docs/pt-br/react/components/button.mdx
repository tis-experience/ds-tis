    <Aside type="caution" title="Registry beta">
      A distribuição é por source. `@tis/react` não é um pacote público; revise
      o arquivo instalado como parte do código da aplicação.
    </Aside>

    <h3>Instalação</h3>

    Configure primeiro o namespace conforme o [catálogo do registry](../../registry/).

    <Tabs syncKey="package-manager">
      <TabItem label="npm">

```sh
npx shadcn@latest add @tis/button
```

      </TabItem>
      <TabItem label="pnpm">

```sh
pnpm dlx shadcn@latest add @tis/button
```

      </TabItem>
      <TabItem label="yarn">

```sh
yarn dlx shadcn@latest add @tis/button
```

      </TabItem>
      <TabItem label="bun">

```sh
bunx --bun shadcn@latest add @tis/button
```

      </TabItem>
    </Tabs>

    O item instala `button.tsx`, o helper compartilhado, as dependências fixadas
    e garante `@import "ds-tis/css"` no CSS global.
  </ComponentPanel>

  <ComponentPanel id="accessibility" label="Acessibilidade" slug="button" technology="react">
    <Aside type="tip" title="Gate executado">
      O Button participa do consumer React/Vite que valida build de produção,
      submit real, foco e Axe junto com os outros oito componentes beta.
    </Aside>

    <h3>Responsabilidade do consumidor</h3>

    <ul>
      <li>fornecer nome acessível por texto ou <code>aria-label</code>;</li>
      <li>declarar <code>type</code> corretamente dentro de formulários;</li>
      <li>preservar estados disabled/loading e o focus ring público;</li>
      <li>validar o contexto real, incluindo textos, fluxo e contraste.</li>
    </ul>
  </ComponentPanel>
