# @tis/react

Workspace privado da biblioteca React vNext.

Estado atual: fundação documental, Storybook e adapters Ark/Zag incrementais.
Accordion, Modal e Popover reutilizam a anatomia, os tokens e o CSS públicos da
v1 enquanto Ark/Zag fornece somente o comportamento. Cada adapter aprovado é
exposto por subpath explícito; a raiz do pacote continua fechada.

Nenhum componente é publicado antes de concluir brief, spec Figma, matriz de
contrato, acessibilidade e teste de consumo. Ark é detalhe interno preferencial
para padrões interativos suportados; elementos HTML nativos continuam sendo a
base quando uma máquina não agrega valor.
