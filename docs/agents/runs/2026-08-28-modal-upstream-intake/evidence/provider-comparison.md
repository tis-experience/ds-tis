# Paridade das quatro saídas — Modal

| Dimensão | HTML/CSS/JS | Ark/Zag | React/shadcn/Base UI | Angular |
|---|---|---|---|---|
| Visual/tokens | estável | contrato TIS | contrato TIS | contrato TIS |
| Portal/backdrop | runtime TIS | Ark/Zag | Base UI | CDK Overlay/Portal |
| Foco/Escape | runtime TIS | Zag | Base UI | CDK A11y/Overlay |
| Sizes | sm/md/lg | sm/md/lg | sm/md/lg | sm/md/lg |
| Desktop md | 640px | 640px | 640px | token `max-width-md` |
| Mobile 390 | 350px | 350px | 350px | contido no viewport |
| Overflow | zero | zero | zero | zero em 320/390/1280 |

Diferenças de altura decorrem do conteúdo de exemplo. Close, ações, anatomia,
tokens e requisitos acessíveis permanecem equivalentes.
