# Brief aprovado — Button

- Problema: disponibilizar a ação Button equivalente nas três saídas públicas.
- Quando usar: disparar ação imediata, confirmar decisão ou enviar formulário.
- Não usar: navegação; links podem receber o visual TIS sem assumir semântica de button.
- Classificação: action control, padrão Button nativo.
- Contrato: nome acessível, Enter/Space, disabled, loading, foco, tamanhos, variantes e formulário.
- Escopo aprovado: adapter Ark Factory, documentação e validação; Web e Figma permanecem unchanged.
